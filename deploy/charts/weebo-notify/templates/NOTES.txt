1. Connect a Notify with an API token:

     kubectl -n {{ .Release.Namespace }} create secret generic notify-admin --from-literal=token=<token>

     kubectl apply -f - <<YAML
     apiVersion: notify.weebo.io/v1alpha1
     kind: NotifyInstance
     metadata:
       name: main
     spec:
       url: https://notify.example.com
       tokenSecretRef:
         namespace: {{ .Release.Namespace }}
         name: notify-admin
         key: token
     YAML

2. Then declare NotifyObject resources referencing it
   (`spec.instanceRef: main`).

`resource.customizations.health.notify.weebo.io_*`.
