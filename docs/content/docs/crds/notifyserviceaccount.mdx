- **API version:** `notify.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `nsa`
- **Guide:** [Install via Helm](/docs/guides/install)

A managed service account of a Notify instance (`[[service_accounts]]`):
a machine identity channels grant scopes to. Rendered into the
instance's configuration; `Ready` once every pod of the instance
applied it. Deleting it **disables the account and revokes all its API
keys** in Notify; declaring it again re-enables it, but its keys stay
revoked.

## Example

```yaml
apiVersion: notify.weebo.io/v1alpha1
kind: NotifyServiceAccount
metadata:
  name: my-serviceaccount
  namespace: team-a
spec:
  displayName: Grafana alerting
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `description` | `string` | no |  |  |
| `displayName` | `string` | no |  |  |
| `id` | `string` | no |  | Its id in Notify, unique on the instance: unset, `metadata.name`. **Immutable**: another id is another account.<br /><br />Constraints: `pattern: ^[a-z0-9]([-_.a-z0-9]*[a-z0-9])?$`, `minLength: 1`, `maxLength: 64` |
| [`instanceRef`](#spec.instanceRef) | `object` | no |  | The instance it belongs to: unset, the only one of this namespace. An instance of another namespace must accept this one (`objectSelector.namespaces`). |

**Rules**

- `id`: id is immutable: delete the service account and create another — `self == oldSelf`

### `spec.instanceRef` [#spec.instanceRef]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `kind` | `string` | no |  | The kind of instance a reference designates.<br /><br />Values: `"Instance"`, `"LocalInstance"` |
| `name` | `string` | yes |  | `metadata.name` of the instance. |
| `namespace` | `string` | no |  | Namespace of a `LocalInstance`. Defaults to this object's own; required on a cluster-scoped object. Another namespace's local instance must share itself with this one (its `sharedWith`). |

**Rules**

- namespace only applies to kind LocalInstance — `!has(self.namespace) || !has(self.kind) || self.kind == 'LocalInstance'`
