- **API version:** `notify.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `nli`
- **Guide:** [Migrate from the Helm chart](/docs/guides/migrate-from-helm-chart)

A Notify instance the operator runs in this namespace: the server's
`Deployment` and its migration `Job`, the web UI, their configuration
(rendered from this spec and the channels, service accounts,
transforms and trust policies that attach to it) and the objects
around them. The database is yours: the instance only reads its URL.
`Ready` tells whether every pod runs the desired configuration.

## Example

```yaml
apiVersion: notify.weebo.io/v1alpha1
kind: NotifyLocalInstance
metadata:
  name: my-localinstance
  namespace: team-a
spec:
  database:
    urlSecretRef:
      name: notify-db
      key: url
  attachments:
    s3:
      endpoint: https://s3.example.com
      bucket: notify
      credentialsSecretRef:
        name: notify-s3
  oidc:
    issuer: https://id.example.com
    clientId: notify
  webPush:
    vapidKeySecretRef:
      name: notify-vapid
      key: key.pem
    contact: mailto:ops@example.com
  ingress:
    className: nginx
    api:
      host: notify.example.com
      tlsSecretName: notify-tls
    web:
      host: app.example.com
```
